# Data Center Energy Demand Forecasting Research

## Authors
- Diego Lopez (UNC Charlotte)
- Matthew De La Rosa (UNC Charlotte)

## Project Overview
This repository contains our research on data center energy demand forecasting, including our proposal, implementation, and findings.

## Repository Structure
```
.
├── proposal/           # Research proposal documents
│   ├── main.tex       # Main LaTeX proposal document
│   ├── figures/       # Figures and diagrams
│   ├── references/    # Bibliography files
│   └── sections/      # Separate section files
├── literature/        # Related research papers and literature
├── data/             # Dataset files (if public)
├── src/              # Source code (if applicable)
└── docs/             # Additional documentation
```

## Getting Started
1. Clone this repository
2. Install LaTeX if you want to compile the proposal
3. Use your preferred LaTeX editor (Overleaf Recommended)
