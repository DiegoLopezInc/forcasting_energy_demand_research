# Data Center Energy Demand Forecasting Research Proposal

This repository contains our research proposal on data center energy demand forecasting.

## Authors
- Diego Lopez (dlopez18@charlotte.edu)
- Matthew De La Rosa (mdelaro2@charlotte.edu)

## Proposal Directory Structure

- `main.tex`: Main LaTeX document
- `figures/`: Directory for storing figures and diagrams
- `references/`: Directory for bibliography files
- `sections/`: Directory for separate section files (if needed)

## How to Use This Template

1. Edit the `main.tex` file to include your specific research details
2. Place any images or diagrams in the `figures` directory
3. Create your bibliography in BibTeX format in `references/references.bib`

## Recommended Tools

- LaTeX Editor: Overleaf (web-based, good for collaboration) or TeXmaker (desktop)
- Reference Manager: Zotero or Mendeley for managing bibliography
- Version Control: Git for tracking changes

## Important Sections to Complete

1. Title: Make it specific and descriptive
2. Abstract: Write this last
3. Introduction: Set the context and motivation
4. Research Objectives: Be specific and measurable
5. Literature Review: Show your knowledge of the field
6. Methodology: Be detailed and justify your approach
7. Timeline: Be realistic and include milestones
8. References: Follow a consistent citation style
